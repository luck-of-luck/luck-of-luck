### 📱 **[AMPLIAGRO OS](https://github.com/luck-of-luck/ampliagro-os)** — Ecossistema Agrícola de Elite

Idealizador e desenvolvedor principal do **Ampliagro**, um ecossistema de gestão agrícola estruturado sob o conceito de **Bento Workspace OS**. Redefine a usabilidade no campo através de acessibilidade, velocidade e design intuitivo.

**Destaques:**
- ✨ Matriz Cartesiana Snapping: Telas dinâmicas baseadas em malhas rígidas simétricas
- 🎨 Design NCS: Interface minimalista livre de poluição visual
- ⚡ Arquitetura Offline-First & SPA: Vanilla JavaScript + Django + Telemetria
- 📊 Dashboards Dinâmicos: Gráficos responsivos e otimizados em tempo real

**Stack:** `Python` `Django` `JavaScript` `Web Telemetry` `SVG Optimization`
